# Referencias visuales del sitio actual

Sube aquí los recursos originales que quieras conservar o usar como referencia.

Estructura:

- `imagenes-originales/`: imágenes usadas en la web actual.
- `gifs-originales/`: GIFs usados en secciones o animaciones.
- `lotties/`: archivos `.json` de Lottie o un `.txt` con enlaces.
- `logos/`: logos en mejor calidad si existen.
- `capturas-diseno-actual/`: capturas del diseño actual en escritorio y móvil.

No subir credenciales, tokens, `.env`, backups de WordPress, bases de datos ni información privada.
